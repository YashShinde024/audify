# Audify Support

Thank you for using **Audify**! Here are the recommended ways to get help, report bugs, ask questions, or contribute feedback.

## Channels

### 1. Bug Reports
If you encounter a bug, audio rendering flaw, UI glitch, or browser incompatibility:
- Search existing [GitHub Issues](https://github.com/YashShinde024/audify/issues) to see if it has already been reported.
- If not, create a new issue using our [Bug Report Template](https://github.com/YashShinde024/audify/issues/new?template=bug_report.yml).
- Include browser version, OS, audio file specs, and reproduction steps.

### 2. Audio DSP & Headroom Quality Feedback
For signal processing questions, limiter behavior, filter characteristics, or encoding issues:
- Use our [DSP / Audio Quality Issue Template](https://github.com/YashShinde024/audify/issues/new?template=dsp_issue.yml).
- Specify sample rates, channels, bit depth, and parameter values.

### 3. Feature & Preset Requests
Ideas for new presets, effects, or standalone audio utilities:
- Open a feature request via the [Feature Request Template](https://github.com/YashShinde024/audify/issues/new?template=feature_request.yml).

### 4. General Questions & Inquiries
- For inquiries about the Audify project or partnership, reach out via the [Audify Contact Form](https://audify.nyxen.in/contact) or email **support@nyxen.in**.

### 5. Security Inquiries
If you discover a security vulnerability or sensitive data issue:
- **Do not** file a public GitHub issue.
- Please review [SECURITY.md](./SECURITY.md) and email **support@nyxen.in** directly with encrypted or private details.
